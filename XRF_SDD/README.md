# Additional raw MCA spectra

This directory contains 20 raw sample spectra added while version 0.2 was being published. Original bytes are retained. Filenames describe different nominal acquisition conditions; the validation in this release concerns `SDD_Spectrum/shafa_50kv_20uA.mca` and the synthetic examples.

Match each sample to its appropriate calibration and common-scale sensitivity before quantitative batch analysis. The original raw files in this directory have not been modified or treated as a shared calibrated dataset.
